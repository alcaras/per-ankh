# Hand-Maintained TypeScript Types

One type per file, re-exported through `index.ts` for convenient imports.

These were **originally** generated by [ts-rs](https://github.com/Aleph-Alpha/ts-rs) from Rust structs in the desktop app's `src-tauri/`. That tree was removed in f97c09a, and with it the generator and the `types:generate` script that drove it. Nothing regenerates this directory any more — each file carries a header saying so.

## Editing

Edit them like any other source file. There is no generator to re-run and no upstream to sync back to; the file in this directory *is* the definition.

They describe the shape of the parsed game blob, so a change here is only half the work: the blob is produced by `src/lib/parser/` and validated by the Worker in `cloud/src/schemas/game.ts`. Changing a type without changing both leaves the annotation lying about the data. See `cloud/src/CLAUDE.md` for the `PARSER_VERSION` and deploy-ordering rules that go with a blob-shape change.
